🚀 INSTALLATION STEPS (Run these in order):

1. Install Docker Engine:
   cd /..../projects/kafka-event-driven-architecture
   ./scripts/install-docker.sh

2. Activate Docker group:
   newgrp docker

3. Start Kafka services:
   ./scripts/start-kafka.sh

4. Verify everything works:
   ./scripts/verify-docker.sh

5. Run C# example:
   cd examples/01-fundamentals/dotnet
   ./run-example.sh

  3. Run examples:  cd examples/01-fundamentals/dotnet && ./run-example.sh

Stop Everything:
  docker compose down

Start Fresh (delete data):
  docker compose down -v

View Kafka UI:
  http://localhost:8080

View Logs:
  docker compose logs -f kafka
